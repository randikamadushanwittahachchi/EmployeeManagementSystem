# 🧑‍💼 Employee Management System

A fully functional, secure, and responsive Employee Management System built using **.NET Web API** and **Blazor WebAssembly**. This project includes JWT-based authentication, role-based access control, and full CRUD functionality for managing employees and departments.

---

## 🚀 Features

- ✅ User authentication with **JWT Bearer Tokens**
- ✅ Role-based access control (Admin/User)
- ✅ CRUD operations for Employees and Departments
- ✅ Responsive UI using **Blazor WebAssembly** and **Bootstrap**
- ✅ Secure API endpoints using **.NET Web API**
- ✅ Database integration with **Entity Framework Core** and **SQL Server**

---

## 🔧 Technologies Used

- **Backend:** ASP.NET Core Web API, JWT Authentication
- **Frontend:** Blazor WebAssembly, Bootstrap
- **Database:** SQL Server, Entity Framework Core
- **Tools:** Visual Studio, Postman, Git, GitHub
